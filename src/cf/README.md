# Каталог src/cf

Выгрузка конфигурации в XML. Объекты подсистем имеют префиксы `ТО_`, `ОП_`, `RMQ_`.

Загрузка: Конфигуратор → «Конфигурация → Загрузить конфигурацию из файлов» → выбрать этот каталог → обновить конфигурацию базы. `ConfigDumpInfo.xml` в репозиторий не кладётся: для полной загрузки он не нужен.
