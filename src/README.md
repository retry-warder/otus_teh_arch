# Каталог src

Исходники решения на платформе 1С:Предприятие 8.3 в формате выгрузки Конфигуратора (XML).

| Каталог | Что внутри |
| --- | --- |
| `cf/` | конфигурация: демо-конфигурация с подсистемами «ТО», «Оценка производительности» и «Обмен RabbitMQ» |
| `cfe/YAXUNIT/` | расширение `YAXUNIT`: движок YAxUnit и модули тестов проекта |
| `epf/` | внешние обработки: `ТО_Шаги` — библиотека шагов Vanessa Automation |
| `erf/` | внешние отчёты (пока нет) |

Формат EDT и формат Конфигуратора не смешиваются: всё выгружено Конфигуратором («Конфигурация → Выгрузить конфигурацию в файлы»).
