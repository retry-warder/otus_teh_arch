# Каталог fixtures

Тестовые данные, макеты и настройки для автоматических тестов.

Сейчас пусто: тесты YAxUnit создают данные конструктором (модули `*_Данные` в `src/cfe/YAXUNIT`), сценарии Vanessa — шагами библиотеки `ТО_Шаги` (`Дано модель ТС…`, `Дано автомобиль…`, `Дано показания…`). Поэтому прогон не зависит от содержимого базы, кроме одного условия: в ней не должно быть других автомобилей с флажком «Планировать ТО».
