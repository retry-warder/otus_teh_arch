# Документация: подсистема «ТО»

Тема курсового проекта — «Формирование нарядов на ТО (расчёт материалов)».

Вся документация проекта собрана в этом каталоге. Состояние на 11.11.2026. Онлайн-версии документов — в проекте «Курс Архитектор 1С», здесь их выгрузка в Markdown. Интерактивные схемы онлайн-версий заменены ссылками; картинки BPMN взяты из `doc/diagrams/4_BPMN/`.

| Файл | Документ |
| --- | --- |
| `01_Технический_проект.md` | архитектура, состав объектов, алгоритмы, обмен RabbitMQ, APDEX, роли, тестирование, развёртывание |
| `02_Спецификация_на_разработку.md` | спецификация по шаблону курса: постановка задачи, требования, технические особенности (раздел 4), Таблица 10 |
| `03_Отчёт_разработчика.md` | выполненные работы, принятые решения, соответствие стандартам, статус тестирования |
| `04_План_тестирования.md` | этапы и проверки, протокол результатов |
| `diagrams/` | диаграммы C4, ER, BPMN и прототипы форм; описание — `diagrams/README.md` |
| `course/` | документы сдачи в Word и PowerPoint: технический проект, спецификация, отчёт разработчика, презентация к защите |

Технический проект ссылается на техническое задание, которого в репозитории нет. Термины и требования ФТ1–ФТ12, НТ1–НТ9 с той же нумерацией приведены в спецификации (разделы 1, 3.3 и 6).
