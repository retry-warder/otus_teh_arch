# Диаграммы курсового проекта: подсистема «ТО» в демо-конфигурации

Состояние на 11.11.2026 (BPMN), 07.11.2026 (остальное) — по фактической выгрузке конфигурации (платформа 8.3.23). В конфигурации три подсистемы: «ТО» (префикс `ТО_`), «Оценка производительности» (`ОП_`) и «Обмен RabbitMQ» (`RMQ_`). Обмен со складом идёт через RabbitMQ по схеме outbox / inbox. По событию склада создаётся документ `ТО_СкладскаяЗаявка`.

| Папка | Нотация | Что внутри | Файлы |
| --- | --- | --- | --- |
| `1_C4` | C4-PlantUML | 1 — контекст, 2 — контейнеры (с внешней компонентой PinkRabbitMQ), 3 — компоненты трёх подсистем, 4 — динамика формирования нарядов, 5 — динамика обмена со складом |`.png`|
| `2_ER_объекты_1С` | diagramobject (1ce-icons-for-plantuml, расширенная схема) | 1 — объекты ТО и связи, 2 — реквизитный состав объектов ТО, 3 — объекты ОП и RMQ с реквизитами |`.png`|
| `3_Прототипы_форм` | «Накидка» (md_design) | F1–F8 — формы ТО; F9 — документ «Складская заявка» (закладки «Заявка» и «История»); F10 — список складских заявок | `.txt`, `.png` (для форм с закладками — по картинке на закладку)|
| `4_BPMN` | BPMN 2.0 (фигуры draw.io) | AS IS; 0 — сквозной процесс со складом и кладовщиком; 1–4 — формирование, запись, закрытие наряда, рассылка; 5 — событие складу через RabbitMQ и складская заявка |`.png` |

## Цвета

- **C4:** голубые — компоненты подсистемы «ТО», оранжевые — «Оценка производительности», бирюзовые — «Обмен RabbitMQ», серые — внешние системы. Пунктиром — перспектива: система мониторинга транспорта.
- **ER:** белые — объекты ТО, оранжевые — ОП, голубые — RMQ, серые — типовые объекты демо-конфигурации.
- **BPMN:** жёлтые задачи выполняют люди, голубые — система.
